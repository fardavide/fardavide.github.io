# fardavide.dev

Davide Farella's personal website: one static page (hero, screenshot filmstrip, facts grid, four
project cards, footer) implemented from a Claude Design project and published to GitHub Pages at
fardavide.github.io (the fardavide.dev domain is not attached yet). No blog, no CMS, no backend.
Repository: `fardavide/fardavide.github.io`.

## Tech stack (decided, do not substitute)

- Vite + TypeScript with **no framework** and no CSS framework. The page is hand-written HTML
  and CSS from the design; TypeScript exists for the theme override only.
- npm with a committed lockfile. Not pnpm.
- Vitest for unit tests, Playwright (Chromium only) for screenshot tests, ESLint with the strict
  type-checked typescript-eslint configs, Prettier, `tsc --noEmit`.
- Published from the `gh-pages` branch by a workflow, mirroring oltre.space. Not
  `actions/deploy-pages`.

## Architecture

Presentation only. `index.html` and the stylesheet are the page; pure logic (the theme override)
lives in a module with no DOM imports and is unit-tested; one module wires it to the document.
There is no domain or data layer because the site holds no data. Details in
`.ai/docs/architecture.md`.

## Conventions that differ from defaults

- Under `prefers-reduced-motion: reduce` every animation is off, and that is also what the
  screenshot tests emulate.
- Screenshot baselines are recorded on a Mac and verified on `macos-26`. Never on Linux, never
  regenerated by CI.
- Tests are named for behaviour (`should … when …`); test doubles are handwritten.

## Build and test

`npm run build`, `npm test`, `npm run lint`, `npm run format:check`, `npm run typecheck`,
`npm run test:screenshots`. `main` is protected by the `protect-main` ruleset: branch, PR, all
five checks green, squash merge. No bypass exists for anyone. A merge that touches the page
publishes it through `.github/workflows/pages.yml`. Details in the `build-and-test` skill.

## Sanctioned tooling

The built-in file tools read and edit source; symbol search is the built-in Grep and Glob (no
code index is configured). The npm scripts above are the only path for build, test and lint. If
one fails, the failure is the finding: report it, do not route around it.
